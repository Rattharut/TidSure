=============================================================================
ภาพพื้นหลังการ์ดในหน้าทำข้อสอบ — ต้องมี 5 ไฟล์
=============================================================================

ขนาดที่ต้องการ: 900 x 400 px  (ทุกไฟล์ขนาดเดียวกันหมด)

ชื่อไฟล์ (ต้องตรงเป๊ะ ตัวพิมพ์เล็ก ใช้ขีดกลาง ห้ามเว้นวรรค):

  ขั้นเลือกโหมด (2 การ์ด)
    background-dungeon.png   -> โหมดดันเจี้ยน   (ภาพประตูดันเจี้ยนมีคบไฟ)
    background-dragon.png    -> โหมดจำกัดเวลา   (ภาพมังกรในป่า)

  ขั้นเลือกระดับความยาก (3 การ์ด)
    difficulty-easy.png      -> ง่าย
    difficulty-medium.png    -> ปานกลาง
    difficulty-hard.png      -> ยาก

-----------------------------------------------------------------------------
กฎการจัดวางองค์ประกอบในภาพ (สำคัญมาก)
-----------------------------------------------------------------------------

  [ ซ้าย 40% ]              [ ขวา 60% ]
  โดนตัดทิ้ง +               วางตัวเอกตรงนี้
  โดนชั้นสีดำทับ             (มังกร ประตู มอนสเตอร์ ฯลฯ)
  (ตัวหนังสืออยู่ตรงนี้)

  - ภาพถูกครอบตัดโดยยึด "ขอบขวา" เป็นหลัก
  - การ์ดระดับความยากแคบกว่าการ์ดโหมด ด้านซ้ายของภาพจะโดนตัดเยอะกว่า
  - ครึ่งล่างซ้ายมีชั้นสีเข้มทับอยู่ เพราะเป็นที่วางชื่อการ์ด
    อย่าวางรายละเอียดสำคัญตรงนั้น เพราะจะมองไม่เห็น

-----------------------------------------------------------------------------
เรื่องอื่น
-----------------------------------------------------------------------------

  - ถ้าไฟล์ไหนยังไม่มี เว็บไม่พัง แค่การ์ดนั้นไม่มีภาพพื้นหลัง
  - แนะนำภาพโทนเข้ม เพราะเว็บเป็นธีมมืด ภาพสว่างจัดจะแย่งสายตากับตัวหนังสือ
  - ถ้า export เป็น .webp ได้ ไฟล์จะเล็กลงราว 30-50%
    แต่ต้องแจ้งให้แก้นามสกุลใน src/pages/TakeQuiz.jsx ด้วย
  - ไฟล์ README.txt นี้ลบทิ้งได้เมื่อใส่ภาพครบแล้ว
